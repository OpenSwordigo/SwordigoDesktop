Building from Source

Requirements: GCC, G++, aarch64-linux-gnu-gcc, SDL3, SDL3_image, OpenGL, Unicorn Engine, OpenAL Soft, libvorbis, zlib.

# Install required dependencies (Debian/Ubuntu)
sudo apt install build-essential gcc-aarch64-linux-gnu libsdl3-dev libsdl3-image-dev libgl-dev libunicorn-dev libopenal-dev libvorbis-dev zlib1g-dev

# Clone and compile
git clone https://github.com/TheCorrectSynovian/SwordigoDesktop.git
cd SwordigoDesktop
make -j$(nproc)
./run_swordigo.sh
