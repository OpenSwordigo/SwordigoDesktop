2. Ghidra Decompilation & Legacy Engine Audit

Analysis of Touch Foo's CaverEngine decompilation (derived from CaverShell.c, GameSceneController.c, and RenderingContext.c).

Legacy Fixed-Function GLES 1.1

The original engine relies on immediate matrix stacks (glMatrixMode, glPushMatrix) and raw CPU RAM arrays passed to glVertexPointer. SRE hooks intercept these rendering calls, caching data into GPU Vertex Buffer Objects (VBO).

Atomic Spinlock Bottlenecks

Copy-on-write std::string refcount operations utilized LDXR/STXR exclusive store loops, creating massive thread stalls under ARM emulation. SRE replaces these functions with non-atomic single-threaded routines.
