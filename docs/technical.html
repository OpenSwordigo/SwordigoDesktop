Technical Architecture & System Specifications

Comprehensive engineering breakdown of the host compatibility engine, Dynarmic A64 JIT execution core, and SRE guest runtime trampolines.

1. System Execution Stack

Swordigo Desktop operates as a single x86_64 host process. Rather than running a full Android guest OS, it executes original ARM64 guest machine instructions directly through Dynarmic JIT compilation while intercepting system calls.

2. Active SRE Guest Trampoline Inventory (34 Hooks)

The Swordigo Runtime Engine (SRE) maps native C11 function overrides at guest address 0x2000000. Absolute 16-byte ARM64 trampolines replace original target function entries.

Category Target Symbol / Address Host Intercept Function Technical Impact
Memory / String 0x566bb8 (CppString::from_char_p) sre_CppString_from_char_p Eliminates GNU COW atomic reference count spinlocks.
GUI / Overlay 0x4a28bc (GUIWindow::DrawRect) sre_GUIWindow_DrawRect Renders vector UI buttons and HUD overlays directly.
Audio Subsystem 0x4811a0 (PlayMusicWithName) sre_PlayMusicWithName Decouples JNI audio calls to native OpenAL Soft 3D positional audio.
Scene Loop 0x34ed2c (GameSceneView::Update) sre_GameSceneView_Update Enforces a deterministic 60Hz physics step decoupled from display FPS.
Exception Guard 0x572110 (luaD_throw) sre_luaD_throw Prevents guest Lua VM longjmp unwinding crashes.

3. Virtual Memory Map Specification

Host memory buffer allocated via page-aligned virtual allocation, mapping guest addresses to fixed host offsets.

Guest Virtual Range Allocated Subsystem Access Permissions Description
0x00000000 - 0x00FFFFFF Null Page Guard & TLS No Access (PROT_NONE) Catches null pointer dereferences and guest stack underflows.
0x01000000 - 0x01FFFFFF libswordigo.so Read / Execute / Write Original game engine text, rodata, and data segments.
0x02000000 - 0x02FFFFFF libsre.so (Guest SRE) Read / Execute / Write SRE guest trampoline runtime and custom Lua bindings.
0xFF000000 - 0xFF100000 JNI Bridge & Signal Handler Read / Execute Emulated Android JNI vtable and Bionic system call entries.
