Project Overview

SwordigoDesktop is an open-source native Linux binary compatibility layer, software development kit (SDK), and modding framework for Touch Foo's action-adventure RPG Swordigo.

Rather than utilizing full OS virtualization or high-overhead Android emulators, SwordigoDesktop implements a targeted binary-translation architecture that maps original ARM64 ELF segments (libswordigo.so) into host memory, translating machine instructions via Dynarmic JIT and routing graphics and audio system calls directly to native SDL3, OpenGL, and OpenAL Soft APIs.

Dynarmic ARM64 JIT

Translates guest ARM64 instructions directly to host x86_64 machine code with 512MB code cache allocation and targeted x86_64 FMA fast-paths.

SRE Guest Trampolines

Injects 34 native function trampolines at guest address 0x2000000 to replace GNU atomic string spinlocks, thread stalls, and mobile rendering limits.

FBO Viewport Scaler

Decouples 960x544 native game rendering from desktop window resolution with custom GLSL upscalers (AMD FSR 1.0, Sharp Bilinear, CRT Scanlines).

Quick Start

Build and run the runtime on x86_64 Linux systems (Debian, Ubuntu, Fedora):

# Install dependencies (Debian / Ubuntu)
sudo apt install build-essential gcc-aarch64-linux-gnu libsdl3-dev libsdl3-image-dev libgl-dev libunicorn-dev libopenal-dev libvorbis-dev zlib1g-dev

# Clone repository and execute build wrapper
git clone https://github.com/TheCorrectSynovian/SwordigoDesktop.git
cd SwordigoDesktop && ./run_swordigo.sh
